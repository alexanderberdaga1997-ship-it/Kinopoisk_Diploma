# Дипломный проект Skypro — тестирование Кинопоиска

## Описание проекта

Проект демонстрирует ручное и автоматизированное тестирование веб-интерфейса Кинопоиска и REST API стороннего сервиса PoiskKino.

**Объекты тестирования:**

- **UI:** https://www.kinopoisk.ru/
- **API:** https://api.poiskkino.dev/v1.4

**Важно:** PoiskKino — сторонний сервис, а не официальный API сайта kinopoisk.ru. UI- и API-тесты выполняются для разных сервисов.

## Технологии

Python, pytest, Selenium WebDriver, Requests, Allure Report, Postman.

## Автоматизированные проверки

**UI — 5 функциональных тестов:**

1. Поиск фильма «1+1».
2. Переход из результатов поиска в карточку фильма.
3. Отображение названия и года фильма.
4. Открытие каталога фильмов.
5. Открытие каталога сериалов.

Дополнительно реализован один технический тест запуска браузера.

**API — 5 тестов:**

1. Получение списка фильмов — позитивный.
2. Получение фильма по ID — позитивный.
3. Поиск фильмов по названию — позитивный.
4. Запрос без API-токена — негативный.
5. Запрос с неверным API-токеном — негативный.

**Всего: 11 автотестов.**

## Установка и настройка

Необходимы Python 3.12 или совместимая версия и установленный Google Chrome.

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Установить зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Для позитивных API-тестов необходим действующий токен PoiskKino. В PowerShell его можно задать для текущей сессии:

```powershell
$env:KINOPOISK_API_TOKEN = Read-Host "Введите API-токен"
```

Токен нельзя добавлять в исходный код или публиковать на GitHub.

Адреса задаются в `config.py`. При необходимости их можно переопределить через переменные окружения `KINOPOISK_API_URL` и `KINOPOISK_UI_URL`.

## Запуск тестов

**Все тесты:**

```powershell
.\.venv\Scripts\python.exe -m pytest
```

**Только UI-тесты:**

```powershell
.\.venv\Scripts\python.exe -m pytest -m "ui"
```

**Только API-тесты:**

```powershell
.\.venv\Scripts\python.exe -m pytest -m "api"
```

Все три режима были успешно проверены во время подготовки диплома.

## Отчёт Allure

Запуск с формированием результатов:

```powershell
.\.venv\Scripts\python.exe -m pytest --alluredir=allure-results --clean-alluredir
```

Для просмотра отчёта необходима отдельно установленная программа **Allure Commandline**:

```powershell
allure serve allure-results
```

Если команда `allure` не распознаётся, следует указать полный путь к `allure.bat`.

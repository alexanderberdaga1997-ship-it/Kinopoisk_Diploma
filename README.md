# Kinopoisk Diploma — автоматизация тестирования

## Описание проекта

Дипломный проект по тестированию веб-интерфейса Кинопоиска и REST API стороннего сервиса PoiskKino.

**Объекты тестирования:**
- UI: https://www.kinopoisk.ru/
- API: https://api.poiskkino.dev/v1.4

PoiskKino является сторонним API и не представляет собой официальный API сайта kinopoisk.ru.

## Технологии

Python, pytest, Selenium, Requests, Allure.

## Покрытие тестами

- 5 функциональных UI-автотестов: поиск фильма, переход в карточку, проверка сведений о фильме, открытие разделов фильмов и сериалов.
- 5 API-автотестов: получение списка, получение по ID, поиск, запрос без токена, запрос с неверным токеном.
- 1 дополнительный технический тест открытия сайта в Chrome.

**Всего: 11 автотестов.**

## Установка

Необходимы Python и Google Chrome.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Настройка API

Для позитивных API-тестов необходим действующий токен PoiskKino.

Токен задаётся в переменной окружения `KINOPOISK_API_TOKEN`. Например, в PowerShell:

```powershell
$env:KINOPOISK_API_TOKEN = Read-Host "Введите API-токен"
```

Токен не следует записывать в исходный код или публиковать в GitHub.

При необходимости адреса можно изменить через переменные `KINOPOISK_API_URL` и `KINOPOISK_UI_URL`.

## Запуск тестов

Все тесты:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Только UI:

```powershell
.\.venv\Scripts\python.exe -m pytest -m "ui"
```

Только API:

```powershell
.\.venv\Scripts\python.exe -m pytest -m "api"
```

## Allure

Для сохранения результатов выполните:

```powershell
.\.venv\Scripts\python.exe -m pytest --alluredir=allure-results --clean-alluredir
```

Для просмотра отчёта необходима установленная программа Allure Commandline:

```powershell
allure serve allure-results
```

Если Allure не добавлен в PATH, используйте полный путь к исполняемому файлу.
